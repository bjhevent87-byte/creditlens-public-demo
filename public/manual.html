비상장기업도 같은 기준으로,
자료 출처는 더 엄격하게.

공시 수치가 없는 기업은 고객이 제출한 연간 재무 CSV로 먼저 계산합니다. 사업보고서·감사보고서 PDF는 원본 대조자료로 연결하며, 수치를 자동으로 읽었다고 표시하지 않습니다.

① 고객 제출 CSV② 재무 검증·추세③ 원본 대조 과제
분석 중에는 기업명·CSV 수치·신청액이 이 사이트의 분석 API로 전달됩니다. CreditLens 사건·파일 저장소에는 보관하지 않습니다. PDF는 브라우저 탭 안에서만 선택되며 서버에 전송되지 않습니다.
01 / 입력

고객 제출 재무자료

금액은 선택한 단위로 입력하고, 빈칸을 0으로 바꾸지 않습니다.

연간 재무 CSV · 2~4개년기간별 별도재무제표. 필수 열: 연도·매출·영업이익·영업현금흐름·자산·부채·자본.
사업·감사보고서 PDF · 선택이 브라우저 탭에서 파일명·SHA256을 대조용으로 표시합니다. PDF의 수치는 아직 자동 추출하지 않습니다.
첨부 원본 없음

원본 파일의 진위, 감사의견, 주석상 담보·보증·차입만기는 담당자가 확인해야 합니다. 자동 승인·한도 산정에 사용하지 마세요.

CSV 양식을 내려받아 재무제표 값을 입력해 주세요.

02 / 검증 원칙

숫자를 먼저 믿지 않습니다

  1. 연도·단위 대조

    2~4개년 자료와 금액 단위가 맞는지 확인합니다.

  2. 재무상태표 일치

    자산=부채+자본이 어긋나면 분석을 멈춥니다.

  3. 현금흐름 교차확인

    영업·투자·재무 현금흐름과 현금잔액 차이를 표시합니다.

  4. 원본·주석 확인

    CSV와 PDF의 계정 정의·감사의견·차입조건은 자동 확정하지 않습니다.

사업보고서 제출대상 비상장법인은 공시 검색에 잡힐 수 있습니다. 이 경우 상장·공시기업 분석도 먼저 확인하세요.
