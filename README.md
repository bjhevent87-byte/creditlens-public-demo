# CreditLens 기업여신 의사결정 지원 플랫폼

공시 재무자료를 예쁘게 보여주는 데서 끝나지 않고, 숫자 사이의 관계를 찾아 여신 상담과 현장실사에서 **다음에 무엇을 확인해야 하는지** 제시하는 로컬 웹 MVP입니다.

## 공개 데모 배포 (Vercel)

`vercel.json`과 `api/index.mjs`는 Vercel용 공개 데모입니다. 배포판은 사건·증빙 저장 API를 서버에서 차단하고 화면에서도 저장/첨부 UI를 숨깁니다. 로컬 4180판의 저장 기능은 유지됩니다. 실제 고객정보는 공개 데모에 입력하지 마세요.

1. Vercel에 로그인하고 프로젝트 루트를 이 `credit-decision-platform` 폴더로 지정합니다. Framework Preset은 **Other**이며 정적 파일은 `public/`에서 제공됩니다.
2. Vercel 프로젝트의 Environment Variables에 `OPEN_DART_API_KEY`, `ECOS_API_KEY`, `KOSIS_API_KEY`를 **Production·Preview의 Sensitive 변수**로 직접 등록합니다. 로컬 `.env` 파일을 업로드하지 마세요. `.vercelignore`가 `.env`, 사건·첨부 및 로그를 제외합니다.
3. `vercel deploy`로 Preview를 검증한 뒤 `vercel deploy --prod`로 운영 URL을 만듭니다. `/api/health`에서 `publicDemo: true`와 데이터 연결 상태를 확인하고 `/api/cases`가 403인지 검사하세요. 키를 추가·변경한 뒤에는 재배포가 필요합니다.

배포판은 저장소나 사용자 인증이 없는 교육용 공개자료 분석판입니다. Vercel의 함수 파일시스템은 영속 저장소가 아니므로 실제 사건 저장은 별도 인증·접근통제·영속 DB/객체저장소 설계 후 구현해야 합니다.

## 이번 MVP 범위

- 기업명·종목코드 검색
- OpenDART 3개년 사업보고서 재무 수집
- 손익·재무상태·현금흐름·차입금의 공통 모델 변환
- 매출·CFO, 채권·재고, 차입·이자보상 관계 분석
- 수익성·성장성·안정성·활동성·현금창출력의 3개년 경영성과 추세 분석
- 재무 체질을 바탕으로 한 금리·환율 민감도 가설과 검증자료 제시
- 이상징후별 가능한 원인과 추가 확인자료 제시
- 한국은행 ECOS 금리·환율·수출·BSI 스냅샷
- 운전자금과 시설자금의 분리 검토
- 사용자 가정 기반 Stress Test
- 위험 기반 현장실사 체크리스트와 가동률 입력
- 상담 사전분석, 현장실사 체크, 심사의견 초안, 출처 화면
- 신규 대출 기본 이자를 포함한 금리 민감도, 기존 변동금리 비중·외상매출 비중 입력
- 고객 입력 월별 현금수지·기존 원리금과 연도별 상환가능현금에 따른 자금용도별 상환표·입력가정상 금액 상한·만기 및 금리 가정별 비교
- 최근 중간재무의 전년 동기 비교, 감사의견·공시 주석 원문 확인 경로
- 화면의 `분석결과 → 현장실사 체크리스트 → 심사의견` 3단계 분리와 요약 의견서
- 업종별 공식 통계 후보 메뉴와 원자료 출처 링크(세부 업종 수치는 수동 입력·검증 전)
- 우려 항목별 증빙파일·담당자 판단 메모·재판단 상태, 로컬 사건 저장과 수정 이력
- 업종지표와 기업 노출비중의 수동 연결(원자료 검증 전 표시)
- 교육용 2차전지 시나리오(외부 API 없이 전체 흐름 검증)

## 실행

```powershell
cd "credit-decision-platform"
node server.mjs
```

또는 `START_LOCAL.cmd`를 실행한 뒤 [http://localhost:4180/](http://localhost:4180/)을 엽니다.

Windows 로그인 시에는 시작프로그램의 `CreditLens 4180 AutoStart` 바로가기가 `START_AUTO.vbs`를 숨김 실행합니다. 4180 서버가 이미 켜져 있으면 중복 실행하지 않고, 꺼지면 다시 시작합니다. OneDrive 프로젝트 파일 준비를 기다리므로 로그인 직후에는 잠시 시간이 걸릴 수 있습니다. 자동 실행 기록은 `data/autostart.log`에서 확인할 수 있습니다. 기존 작업 스케줄러의 동명 작업은 중복을 막기 위해 비활성화했습니다.

이 프로젝트 폴더에 `.env`가 없으면 이전 `investment-platform/current/.env`를 읽기 전용으로 탐색합니다. 키를 별도로 설정하려면 `.env.example`을 `.env`로 복사하고 값을 입력하세요. API 키는 브라우저로 전달되지 않습니다.

## 테스트

```powershell
npm test
```

외부 호출 없이 재무비율, 이상징후, Stress Test 계산 규칙을 검증합니다. 화면 검증은 `2차전지 예시 불러오기`를 눌러 수행할 수 있습니다.

## 상환구조와 증빙 입력

1. 기업 분석 후 상담 입력의 금리·상환방식 가정을 입력합니다. 이 금리는 **은행 제시금리나 자동 산출금리가 아닙니다.**
2. 공시 총차입금과 금융비용만으로 과거 금융비용 완충력과 신규대출의 기본 이자 시나리오를 볼 수 있습니다. 차입별 명세는 필수가 아닙니다. 금리변화·12개월 내 만기집중·차환위험을 정밀하게 볼 때만 펼쳐서 잔액·만기·금리유형을 등록하세요. 전체 명세 확인 표시와 공시 잔액 대조가 끝나면 변동금리 비중을 스트레스 테스트에 자동 연결합니다.
3. 월별 상환가능현금·기존 원리금·사용가능 기초현금, 시설자금 기간의 연도별 상환가능현금·기존 원리금을 입력합니다. 금액 단위는 억원이고 쉼표로 각 월/연도 값을 구분합니다. 차입 명세의 잔액·만기와 월별 원리금표의 일치 여부는 담당자가 확인해야 합니다.
4. 운전자금은 월말 최소현금, 시설자금은 사용자가 입력한 목표 원리금상환배율로 검토합니다. 두 자금이 함께 있으면 통합 일정도 확인합니다. 6·12·24개월/3·5·7년 만기와 입력금리 주변의 가정금리도 비교하지만, 은행의 금리 제안이나 승인 한도는 아닙니다. 미입력값은 0으로 대체하지 않습니다.
5. `사건 저장` 후 고객 PDF·Word·Excel·CSV·이미지 파일(각 10MB 이하)을 우려 항목에 첨부할 수 있습니다. 현장실사 질문에서는 PDF·PNG·JPG 파일을 해당 항목에 직접 첨부할 수 있으며, 첫 첨부 시 사건이 로컬에 자동 저장됩니다. 원본 파일과 SHA256 해시를 보관하고 현장실사 점검 리포트에는 항목별 파일명을 표시합니다. OCR·자동 판독은 아직 제공하지 않습니다. 파일 첨부만으로 위험은 해소되지 않으며 담당자 메모와 검증 상태가 필요합니다.

사건 데이터와 첨부파일은 `data/cases/`에 로컬 저장되며 Git 추적에서 제외됩니다. 서버는 `127.0.0.1`에만 바인딩합니다. 이 폴더는 암호화 저장소가 아니므로 실제 고객의 민감정보를 넣기 전 조직의 보안정책·접근통제·백업 요건을 확인해야 합니다.

## 데이터 상태

- `확인`: 공식 API에서 직접 확인
- `계산값`: 공식 원자료로 계산
- `AI 해석`: 향후 AI 모듈이 생성할 영역
- `사용자 입력`: 현장실사·상담 입력값
- `자료없음` 또는 `조회실패`: 결측을 0으로 바꾸지 않음
- `교육용`: 기능 검증용 시나리오이며 실제 기업 자료가 아님

2026년을 분석연도로 선택해도 연간 사업보고서가 아직 없다면 연간 추세는 2023~2025년으로 유지합니다. 최신 2026년 반기·분기 누적 실적은 전년 같은 기간과 따로 비교해 분석 화면과 심사의견에 표시합니다. 연간 수치와 중간재무를 직접 합산하지 않습니다.

`KOSIS_API_KEY`를 `.env`에 설정하고 서버를 재시작하면 업종지표 연결에서 KOSIS 통계표를 검색하고, 표·수록주기·세부 계열을 선택해 최신값과 직전값을 공식 API로 불러옵니다. 업종명만으로 특정 통계 계열을 자동 확정하지 않습니다. 담당자는 회사의 실제 매출노출 비중과 그 근거를 별도로 입력해야 하며, 근거 없는 산업위험 자동 경고는 만들지 않습니다. 관세청 등 KOSIS 이외의 출처는 계속 수동 입력·원자료 검증 전으로 표시합니다. [KOSIS 통계자료 API](https://kosis.kr/openapi/)에서 큰 통계표는 계열 전체 조회가 제한될 수 있으므로 더 세분화된 표를 선택하세요.

| 재무분석 | 수익성·안정성·현금흐름·회전주기 | 업종별 계정 매핑 고도화 | 높음 |
| 산업분석 | ECOS 공통지표, KOSIS 통계표 검색·공식 수치 조회, 기업 노출 입력 | 업종·품목별 정확한 통계 계열 추천 및 관세청 연동 | 높음 |

| 현장실사 | 위험 기반 질문·가동률, 증빙 첨부와 로컬 버전 이력 | 증빙 내용 자동 대조·검토자 승인흐름 | 중간 |

## 개발 로드맵

1. Phase 1: DART 계정 매핑, 차입금·이자비용·감사정보 정밀화
2. Phase 2: KOSIS·관세청·KDI 산업/전망 데이터와 업종 매핑
3. Phase 3: 월별 자금수지, Debt Capacity, DSCR, 만기구조 분석
4. Phase 4: 고객자료 업로드 및 현장실사 이력의 심사부 검토 체계와 데이터 불일치 자동 탐지
5. Phase 5: 근거 인용형 AI 심사의견과 DOCX/PDF 내보내기

최종 대출 승인, 내부등급, 담보인정비율은 은행 정책이 없는 상태에서 자동 산출하지 않습니다.
